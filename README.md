# COS 106 – Introduction to Web Technologies
Project Title: Design and Develop a Responsive Student Portfolio and Academic Management Website

Live Link: [Visit site](https://chimamanda-justus.vercel.app/)

## Project Overview
Each student is required to design and develop a fully functional multi-page website that serves as a personal academic portfolio and student management platform. The project must demonstrate proficiency in HTML, CSS, and JavaScript while adhering to modern web design principles.

The website should be designed as though it will be used by a university student to showcase their profile, skills, academic achievements, projects, and manage personal academic activities. It should be hosted and the link submitted along with the link to the GitHub repository (folder for the website).
Functional Requirements

1. Homepage
The homepage should contain:
- Student name and photograph
- Welcome message
- Navigation menu
- Brief biography
- Professional-looking layout

2. About Me Page
Include:
- Educational background
- Career aspirations
- Technical skills
- Hobbies and interests

3. Projects Page
Display at least:
- Three sample projects
- Project descriptions
- Images/screenshots
- Links (real or simulated)

4. Academic Planner Page
Develop an interactive planner where users can:
- Add tasks
- Mark tasks as completed
- Delete tasks
JavaScript must be used to implement this functionality.

5. Contact Page
Create a form containing:
- Name
- Email Address
- Phone Number
- Message

JavaScript validation should ensure:
- No field is empty
- Email format is valid
- Phone number contains only digits

## Technical Requirements
### HTML Requirements
Students must demonstrate:
- Proper semantic HTML elements
- Forms
- Tables
- Images
- Hyperlinks
- Lists
- Multimedia (video or audio)

### CSS Requirements
Students must demonstrate:
- External CSS stylesheet
- Responsive design
- Flexbox and/or CSS Grid
- Navigation styling
- Animations or transitions
- Consistent colour scheme
- Mobile-friendly interface

### JavaScript Requirements
Students must demonstrate:
- Event handling
- DOM manipulation
- Form validation
- Dynamic content updates
- Arrays and functions
- Interactive task management system
